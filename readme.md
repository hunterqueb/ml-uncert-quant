# ML Uncertainty Propagation

## Replicate DDDAS 26 Results

```
$ ./uncertPropDDDAS.sh pdf
```

 - generates results in PDF form
 - compares lstm to mamba in 2bp and 3bp

## Other Scripts
 - Individual system scripts that test muliple propagation lengths, timesteps, and lookbacks are found in the following shell scripts.
```
$ ./uncertPropDuffing.sh
```
```
$ ./uncertProp2BP.sh
```
```
$ ./uncertProp3BP.sh
```

## Dataset Generation
Two body problem dataset is generated from GMAT using the API. The dataest in private ASRL repo, but the appropriate data is saved in this repo.

The duffing and 3bp datasets are generated using the scripts in the dataset gen folder and are autogenerated if they do no exist when running the uncertainty propagation shell scripts for the duffing and CR3BP systems.
